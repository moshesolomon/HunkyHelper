## Installation

### Google Chrome
1. **Unzip the file** into a permanent folder.
   > **Note:** Chrome loads the extension directly from this folder, so moving or deleting it later will break the extension.
2. Open `chrome://extensions` in your browser and toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select the `HunkyHelper` folder.
4. Reload `soybooru.com`.

### Mozilla Firefox
1. [Wait for Moshe's SLF ass to upload it on the Mozilla Web Store *(or follow the manual steps below)*:](https://addons.mozilla.org/en-US/firefox/addon/hunkyhelper/)
1. **Unzip the file** anywhere on your computer.
2. Open `about:debugging#/runtime/this-firefox` in your browser.
3. Click **Load Temporary Add-on...** and select the `manifest.json` file inside the unzipped folder.
4. Reload `soybooru.com`.
